Sans clé, Kurate prépare des liens de recherche. Avec une clé, il affiche directement des vidéos. La clé reste dans ce navigateur.

Comment obtenir une clé API gratuite ? (cliquez pour ouvrir)
  1. Allez sur Google Cloud Console – Identifiants (ouvre un nouvel onglet).
  2. Créez ou sélectionnez un projet, puis activez YouTube Data API v3 (1 clic).
  3. Revenez dans "Identifiants", cliquez sur + Créer des identifiants → Clé API.
  4. Copiez la clé générée et collez-la dans le champ ci-dessus.
