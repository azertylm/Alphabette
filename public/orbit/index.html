Chercher sur YouTube

Clé YouTube (nécessaire pour chercher)

La recherche passe par le service officiel de YouTube, qui demande une clé gratuite (console Google Cloud → activer « YouTube Data API v3 » → créer une clé). Elle reste dans ce navigateur. Sans clé, cherchez directement sur YouTube puis collez le lien ici.

Sauvegarde

Votre bibliothèque est enregistrée dans ce navigateur, sur cet appareil. Pour la retrouver ailleurs ou la mettre à l'abri, exportez-la dans un fichier.

Orbit ne télécharge et ne copie aucune vidéo : chaque vidéo est lue par le lecteur officiel de sa plateforme, avec ses propres règles et, parfois, ses publicités.
