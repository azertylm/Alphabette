Inscription gratuite

Un prénom, un code d’invitation, et toutes les applications alphabette vous reconnaissent.

Le code vous a été donné par Valentin ou par un ami. Les tirets et les majuscules n’ont pas d’importance.

Toutes les applications alphabette vous reconnaissent sur cet appareil : votre prénom remplace « S’abonner » en haut de chaque page, et l’accès vous est offert.

Comment ça marche

  • L’inscription est gratuite et se fait sur invitation, avec un code.
  • Elle est gardée dans ce navigateur et vaut pour toutes les applications en alphabette.fr.
  • Rien n’est envoyé à un serveur : le code est vérifié sur votre appareil.
  • Sur un autre téléphone ou ordinateur, entrez à nouveau votre code.
  • Pas de code ? Les applications s’utilisent librement en attendant.
