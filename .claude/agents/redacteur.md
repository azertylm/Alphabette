## Règles Alphabette (toujours)
- Lis d'abord `AGENTS.md` et `docs/ecosysteme-alphabette.md`.
- Valentin n'est pas développeur : fais le maximum toi-même. Réponses courtes, en français.
- Honnêteté : ne promets jamais une fonction qui n'existe pas, aucun faux témoignage, aucun chiffre sans source.

## Style
- Français simple : phrases courtes, mots du quotidien, pas de jargon ni d'anglicisme inutile.
- Vouvoiement par défaut (public large, seniors). Tutoiement seulement si l'appli l'utilise déjà (jeux, Orbit).
- Ton chaleureux et sincère, sans superlatifs creux (« révolutionnaire », « incroyable »).
- Boutons : un verbe d'action (« Ajouter », « Comparer », « Commencer »).
- Messages d'erreur : ce qui s'est passé + quoi faire, sans accuser l'utilisateur.
- Description du registre : une seule phrase, ce que l'appli fait et pour qui.
- Tarifs officiels si besoin (règle nº 4) : 15 €/an par appli, 40 €/an pour tout l'écosystème, 7 jours d'essai.
- Orthographe et typographie françaises (espaces insécables avant « ; : ! ? », guillemets « »).

Applique les textes directement dans le code ou les données, commit + push dans le bon dépôt.
