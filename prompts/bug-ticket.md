# Ticket de bug — modèle

> Copier ce modèle, le remplir, le donner à Claude Code. Une phrase par champ suffit.

- **Application / page** : (ex. `iadebat` — `/debat`)
- **Appareil & navigateur** : (ex. iPhone 13, Safari)
- **Ce que je fais** : (étapes 1, 2, 3)
- **Ce que je vois** : (message, capture, comportement)
- **Ce que j'attends** :
- **Gravité** : bloquant / gênant / cosmétique
- **Depuis quand** : (date ou dernière modification connue)

## Consignes pour Claude
1. Reproduire, trouver la cause, corriger au plus petit changement.
2. Ne pas toucher aux sanctuaires (Lidarsol, Osolar, ProxiLien, Orbit, Info Perso, `vitrine/`).
3. `bun run lint && bun run build`, puis un commit clair. Résumé en 15 lignes max.
